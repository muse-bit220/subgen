# SubGen 字幕 — 動画字幕生成アプリ（iOS）

動画を読み込むと、端末上（オフライン）で音声を文字起こしして字幕を生成するアプリです。
Vrew のような「自動字幕＋翻訳＋書き出し」の基本機能を備えています。

## 機能

- 写真ライブラリ／ファイルから動画を読み込み
- WhisperKit（OpenAI Whisper を端末上で実行）で自動字幕生成
  - モデルは3種類から選択（Large v3 高精度 約626MB / Small 約460MB / Base 約140MB）
  - モデルは初回使用時に自動ダウンロード（以降はオフライン動作）
  - 言語は自動検出／日本語／英語から選択
- 字幕の一覧編集（時刻をタップするとプレビューがその位置にジャンプ）
- 翻訳（英語→日本語／日本語→英語、端末上の Apple 翻訳機能を使用）
- 書き出し
  - SRTファイル（原文のみ／翻訳のみ／バイリンガル）
  - 字幕を焼き込んだ MP4 動画（原文／翻訳／バイリンガル）

## 動作条件

- iOS 18 以上の iPhone
- インストールには AltStore または SideStore が必要

## ビルド方法（GitHub Actions で IPA を作る）

このプロジェクトは GitHub Actions の macOS 環境でビルドして、未署名 IPA を作ります。

1. このフォルダの中身をすべてダウンロードできる状態にします（ZIP を展開）。
2. GitHub で新しいリポジトリを作成します。
   - **Public（公開）がおすすめ**：macOS ランナーの無料枠が大きいため。
   - コードに秘密情報は含まれていません。
3. リポジトリのページで「uploading an existing file」から、展開したファイル・フォルダを
   **すべて**アップロードします。
   - **`.github` フォルダが必須**です（この中にビルド設定が入っています）。
     フォルダごとドラッグ＆ドロップすると中身ごとアップロードできます。
   - `project.yml`、`SubGen` フォルダも忘れずに。
4. アップロードが完了すると自動でビルドが始まります。
   「Actions」タブで進捗を確認できます（目安：10〜20分）。
5. ビルドが成功（緑のチェック）したら、その実行ページ下部の
   「Artifacts」から **SubGen-ipa** をダウンロードします。
6. ダウンロードした ZIP を展開すると `SubGen.ipa` が入っています。
7. AltStore / SideStore で `SubGen.ipa` をインストールします。

### ビルドが失敗したら

- Actions の失敗した実行を開き、赤い × のステップのログを確認してください。
- ログの内容（スクリーンショットやコピー）を Muse に見せれば、コードを修正します。
- ジョブが長時間「待機中（Queued）」のまま進まない場合は、`.github/workflows/build.yml`
  の `runs-on: macos-26` を `runs-on: macos-15` に変えて再実行してください。

## アプリの使い方

1. 「写真ライブラリから選ぶ」または「ファイルから選ぶ」で動画を選択。
2. モデルと言語を確認して「字幕を生成」をタップ。
   - 初回はモデルのダウンロードに数分かかります。
3. 生成された字幕は一覧でそのまま編集できます（不要な字幕は左スワイプで削除）。
4. 必要なら「字幕を翻訳」で翻訳を追加。
5. 「書き出し」から SRT ファイル、または字幕焼き込み動画を共有・保存。

## 備考

- Bundle ID: `com.aramaki.subgen`
- 文字起こしは WhisperKit（argmaxinc/argmax-oss-swift、MIT ライセンス）を使用。
- 翻訳は Apple の Translation framework（iOS 18+）を使用し、端末上で処理されます。
